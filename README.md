# mộc shop

Mẫu website shop bán hàng bằng PHP thuần, HTML, CSS và JavaScript. Dữ liệu sản phẩm đang nằm trong `index.php` để dễ thay bằng MySQL sau này.

## Chạy local

Cài PHP và chạy tại thư mục dự án:

```bash
php -S localhost:8000
```

Mở http://localhost:8000

## Có sẵn

- Lọc theo danh mục và tìm kiếm bằng query string.
- Phân trang phía server với tham số `page`.
- Giao diện responsive, không cần framework.
- JavaScript cho thêm giỏ hàng, yêu thích và form nhận tin.
